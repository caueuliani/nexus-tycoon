# Nexus Tycoon — texto proposto para a página itch.io

**Rascunho para publicação manual.** APK aprovado: `1.0-itch-beta.2` para Android. O beta é gratuito.

## Descrição

Construa uma cadeia industrial espacial, gerencie recursos, contrate pesquisadores e enfrente setores de mineração hostil. Complete missões para subir de patente e use a Ascensão para iniciar uma nova run com melhorias permanentes. A N.O.V.A. acompanha seus primeiros passos com mensagens em texto.

Esta é uma **versão beta em desenvolvimento**. Seu progresso fica no aparelho; login Google e backup manual na nuvem são opcionais. A versão itch.io não oferece anúncios nem compras com dinheiro real. Algumas telas e textos ainda podem receber ajustes.

## Instalação e atualização

1. Baixe o APK Android `Nexus Tycoon 1.0-itch-beta.2` nesta página, depois que a publicação for aprovada.
2. Abra o arquivo no aparelho e autorize a instalação pelo navegador ou gerenciador de arquivos, se o Android solicitar.
3. Inicie Nexus Tycoon. É possível jogar sem login. Para usar o backup manual, vincule sua Conta Google no Perfil e escolha **Salvar na Nuvem**.
4. Em atualizações futuras, instale o novo APK por cima da versão anterior com a mesma assinatura. Não desinstale para atualizar, pois isso pode remover o progresso local. Antes de trocar de aparelho, confira o backup na nuvem.

Requisito configurado no projeto: Android 7.0 ou superior (`minSdk` 24). A compatibilidade com todos os modelos não foi homologada.
